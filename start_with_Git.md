# My Notes
1. Аутентификация 
2. В терминале VSCode выполняем команды 
"git config --global user.name "мой ник""
"git config --global user.email "мой email""
3. Генерируем SSH-ключи чтобы спокойно подключаться к удаленному гиту, выполняем команды в терминале
"ssh-keygen -t ed25519 -C "мой email""
жмем enter, если нам не нужны доп настройки
содержание публичного ключа (.pub) необходимо добавить в аккаунт Git - new SSH key - add SSH key
4. клонируем репозиторий через команду "git clone git@github.com:chi-shi-ba-ni/appsec-jun-roadmap.git"
5. Проверим подключение "ssh -T git@github.com"
6. В VSCode откроем репозиторий через Open Folder (на компе уже создана папка)
Всё готово!

Быстрые удобные команды в VSCode
Ctrl + ~ // открытие терминала

Базовые команды для Git
git status // показывает список файлов и изменения
git add . // подготовка файлов к коммиту, точка - добавить все измененные файлы в очередь на сохранение
git add file_name // подготовка конкретного файла к коммиту
git commit -m "my comment" // сохранение изменений локально на моем компе, добавить комментарий к коммиту
git push // отправляем на удаленный гит (выгружаем мои коммиты с компа на сервер Git)
git pull // получение изменений с удаленного Git локально на мой компьютер
git pull origin "наименование ветки" // получение последних изменений из удалённого репозитория и автоматическое слияние с текущей локальной веткой
